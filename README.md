# opensourcestage
Open Source Stage — the pop-up city A/V playbook, open-sourced 🎁

**Live:** https://shakaleikaumaka.github.io/opensourcestage/ · mirror: opensourcestage-tkt3ezrrju-nqfhvcnv.taur.link

The complete playbook + AI agent for running live A/V and permissionless music jams at any pop-up city.

## 🚀 Raise your own stage agent — anywhere
The agent is **two text files** (instructions = soul, runbook = brain) that live on any model, any platform.
The site's launch section is an **omni-model panorama**: Taurus (our home field), Notion AI (the original path),
Claude Projects, ChatGPT, self-host/OpenRouter, or any chat in a pinch. No vendor gates — a map, not a maze.

The pattern — a soul document plus a knowledge base — is [the ʻohana pattern](https://github.com/shakaleikaumaka/ohana). Fork it for your own agents.
